隐私政策

生效日期：2026 年 11 月 6 日

本政策说明藏音 App 与本介绍网站如何处理信息。App 的本地音乐处理、你主动发送的支持邮件与网站托管是不同场景，请分别阅读。

处理哪些数据，以及如何取得

藏音仅在你选择导入时将音乐复制到 App 的本地存储，并在本机处理与保存音频、内嵌封面、文件名及歌曲标题／歌手／专辑等元数据、内容哈希、收藏、歌单、播放队列与播放位置。来自系统“文件”的访问由系统文件选择器授权；电脑传歌需由你主动开启。

藏音不要求注册或登录，不含广告、分析统计或崩溃收集 SDK，也没有将音乐、用户标识或使用行为自动上传至开发者服务器的功能。App 没有自己的云同步服务。

数据用于什么

音频用于本地播放；封面与元数据用于曲库展示和整理；内容哈希用于识别重复文件；收藏、歌单、队列与播放位置用于保存你的聆听安排与恢复位置。恢复位置不会自动播放。藏音不自动联网获取封面。

局域网传歌与系统备份

电脑传歌只在你开启时接收选择的文件。手机与电脑之间使用明文 HTTP，并非加密传输；访问码用于限制访问，不提供传输加密。请只在可信的私人 Wi-Fi 使用，不要向他人分享地址或访问码。

离开传歌页、App 进入后台或 Wi-Fi／地址变化会停止服务并使当前凭证失效；继续传歌需要重新开启。电脑传歌网页只在浏览器会话内存中保存会话凭证，不使用 cookies、localStorage 或 sessionStorage。停止接收不代表导入结果等全部记录立即消失，文件名可在会话界面保留。

App 未排除操作系统备份。根据系统能力和你的设置，本地资料可能包含在 iCloud 或其他设备／系统备份中；这些备份由系统管理，并不等于藏音提供云同步。

第三方与外部服务

App：没有广告、分析统计或崩溃收集服务。所用本地 HTTP 组件 FlyingFox／FlyingSocks 用于设备间传输，不是开发者的远程上传服务。

支持邮件：你自行选择向 cangyin2026@163.com 写信时，发件人地址、邮件内容及附件会发送到网易邮箱服务，用于接收和回复问题。请不要发送无关的敏感资料。邮箱服务商依其自身适用的隐私政策处理邮件。

本网站：使用 GitHub Pages 托管。访问时 GitHub 会处理请求信息，包括访客 IP 地址，并可为安全目的记录日志；这是网站托管的处理，不是 App 的音乐上传或使用行为统计。本站不嵌入统计脚本、广告或外部字体，也不设置 cookies 或浏览器本地存储。进一步说明见“关于 GitHub Pages”和“GitHub 隐私声明”。

保存多久，以及如何删除

成功导入的本地音乐与相关整理信息会保留至你主动删除；正常完成或失败的传歌会清理暂存上传文件。在歌曲菜单中选择“删除本机副本”并确认，可移除 App 内的音乐副本及其收藏、歌单和队列引用，但不会删除导入来源中的原文件。

卸载 App 会失去未另行备份的本机音乐与歌单。已有系统备份的保留、恢复和删除由系统及你的设置决定，App 内删除不等于删除所有备份。

支持邮件保留在收件邮箱中，用于处理你的问题；如需删除，请通过该邮箱提出请求。邮箱服务商的记录按其政策管理。网站请求日志由 GitHub 按其政策管理。

如何停止或撤回选择

你可以停止电脑传歌、离开传歌页，或在 iOS 设置中关闭藏音的本地网络权限，以停止相关局域网访问。你也可以不再导入文件，并删除 App 内的本地音乐副本；这些操作不会自动删除来源文件或系统备份。

是否联系支持、是否点击外站链接由你选择；停止联系不会自动删除此前邮件，如需删除请来信说明。

隐私问题与联系

如对本政策、数据处理或支持邮件删除有疑问，请联系 cangyin2026@163.com。回复时间视问题复杂程度而定，暂不承诺固定时限。
